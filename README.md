# Muttis tinder für Fotos

Android-App: Fotos aus der Galerie wie bei Tinder durchwischen.

- Nach **links** wischen (oder ✕) = zum Löschen markieren
- Nach **rechts** wischen (oder ♥) = behalten (wird nicht wieder angezeigt)
- ↩ macht die letzte Entscheidung rückgängig
- Gelöscht wird erst am Ende gesammelt, nach Bestätigung durch Android (Papierkorb)

## APK bauen
- Android Studio: Ordner öffnen → Run, oder
- GitHub: Tab *Actions* → *Build APK* → fertige `app-debug.apk` als Artifact herunterladen.

Benötigt Android 11+ (minSdk 30).
